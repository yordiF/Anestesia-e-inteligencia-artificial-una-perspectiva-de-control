# Anestesia-e-inteligencia-artificial-una-perspectiva-de-control
Código de la tesis de posgrado (IIMAS-UNAM) sobre anestesia e IA: predicción del Índice Biespectral (BIS) a partir de propofol y remifentanilo con un modelo híbrido CNN-LSTM-atención entrenado con datos de VitalDB, y regulación de la hipnosis mediante PID sintonizado por algoritmo genético y estimación de ganancias por KNN.
